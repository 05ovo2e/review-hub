# Review Hub 개발 로드맵

Notion을 CMS로 활용해 책, 영화, 드라마 콘텐츠를 관리하고 공개하는 리뷰 플랫폼. 사용자가 Notion에 작성한 콘텐츠를 자동으로 웹사이트에서 탐색하고 리뷰를 열람할 수 있습니다.

## 개요

**Review Hub**는 다음 기능을 제공합니다:

- **콘텐츠 탐색**: 책, 영화, 드라마 유형별로 공개된 콘텐츠를 카드 형태로 탐색
- **상세 리뷰**: 선택한 콘텐츠의 메타정보(제목, 장르, 작가/감독, 평점, 태그)와 Notion에 작성된 리뷰 본문을 확인
- **추천 콘텐츠**: 홈 화면에서 평점 높은 콘텐츠 6개를 빠르게 확인

## 개발 단계

### Phase 1: 프로젝트 초기 설정 ✅

- ✅ Next.js 프로젝트 구조 설정
- ✅ Notion API 연동 환경 구축 (`@notionhq/client` 설치, `lib/notion.ts` 클라이언트 생성, `lib/env.ts`에 `NOTION_API_KEY`/`NOTION_DATABASE_ID` 스키마 추가)
- ✅ 기본 레이아웃 구조 생성

**이유**: 안정적인 개발 기반을 먼저 구축

**예상 소요 시간**: 0.5일 (레이아웃/구조는 완료, Notion 환경 구축만 남음)

**완료 기준**: `@notionhq/client`가 설치되고 환경변수로 Notion API 클라이언트가 정상 초기화된다.

---

### Phase 2: 공통 모듈 개발 ✅

- ✅ Notion API 공통 함수 (콘텐츠 목록 조회, 콘텐츠 상세 조회, 공개 여부 필터링)
- ✅ 공통 컴포넌트 (ContentCard, ContentFilter)
- ✅ 공통 타입 정의 (`types/content.ts`: Content, ContentType, ContentBlock 등)

**이유**: 여러 기능에서 재사용되는 코드를 먼저 구축해 중복을 방지

**예상 소요 시간**: 1~2일

**완료 기준**: Notion DB에서 콘텐츠 목록/상세를 조회하는 함수가 타입 안전하게 동작하고, 콘텐츠 카드 컴포넌트가 더미 데이터로 정상 렌더링된다.

---

### Phase 3: 핵심 기능 개발 ✅

- ✅ 콘텐츠 목록 페이지 (`/contents`): 공개 콘텐츠 카드 목록, 유형 필터, 썸네일/제목/작가·감독/평점 표시
- ✅ 콘텐츠 상세 페이지 (`/contents/[id]`): 메타정보(제목, 유형, 장르, 작가/감독, 평점, 태그, 썸네일) + Notion 리뷰 본문
- ✅ Notion 블록 렌더링 (paragraph, heading, bulleted list, numbered list)
- ✅ 콘텐츠 유형 필터 (책/영화/드라마)

**이유**: Review Hub의 핵심인 콘텐츠 탐색 및 상세 정보 확인 기능을 구현

**예상 소요 시간**: 3~4일

**완료 기준**: 공개 콘텐츠만 목록에 노출되고, 유형 필터가 정상 동작하며, 상세 페이지에서 Notion 리뷰 본문(4개 블록 타입)이 올바르게 렌더링된다.

---

### Phase 4: 추가 기능 개발 ✅

- ✅ 더미 데이터 확대 (각 함수별 충분한 개수 반환)
- ✅ 홈 화면 추천 콘텐츠 6개 표시
- ✅ 콘텐츠 목록 4열 그리드 레이아웃 (데스크톱)
- ✅ 반응형 디자인 점검: 모바일(375px)/태블릿(768px)/데스크톱(1280px) 모두 정상

**이유**: 핵심 기능이 완성된 후 MVP에 필요한 부가 기능을 추가

**예상 소요 시간**: 1~2일

**완료 기준**: 홈 화면에 평점 높은 콘텐츠 6개가 노출되고 상세 페이지로 정상 이동하며, 모바일(375px)/태블릿(768px)/데스크톱(1280px)에서 레이아웃이 깨지지 않는다. ✅ **완료됨**

---

### Phase 5: 최적화 및 배포 ✅

- ✅ 이미지 최적화: Next.js Image 컴포넌트 적용 및 외부 이미지 호스트 설정 완료
- ✅ 반응형 디자인 최종 점검: 모바일(375px)/태블릿(768px)/데스크톱(1280px) 모두 정상
- ✅ Notion API 연동: 실제 Notion 데이터 로드 확인
- ✅ Vercel 배포 및 환경변수 설정

**이유**: MVP 완성 후 실제 서비스 환경에서 사용할 수 있도록 마무리

**예상 소요 시간**: 1~2일

**완료 기준**: PRD의 MVP 완료 기준(`Notion에서 콘텐츠 작성 → Notion API → 콘텐츠 목록 → 유형 필터 → 상세 페이지 → Notion 리뷰 표시`) 흐름이 실제 Notion 데이터로 정상 동작하고, `npm run check-all`을 통과하며 Vercel 배포가 완료된다. ✅ **완료됨 (2026-10-13)**
